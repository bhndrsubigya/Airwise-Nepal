What is AQI?

AQI stands for Air Quality Index. It turns many pollution measurements into one easy number. A low number means clean air. A high number means more pollution and more risk to your health.

AirWise uses the US EPA AQI, a scale used by many apps around the world. Local government scales can use different cut-off numbers.

Who is more sensitive?

👶

Children

Their lungs are still growing, and they breathe more air for their body size. They also play outside a lot.

👴

Older adults

Heart and lung problems are more common with age, and pollution can make them worse.

🫁

People with respiratory conditions

Asthma and similar conditions can flare up when the air is polluted.

👷

Outdoor workers

Long hours outside, often doing physical work, mean more pollution breathed in.

🏃

Athletes

Hard exercise makes you breathe faster and deeper, so more pollution reaches your lungs.

How AirWise Works

AirWise answers one question: "When should I go outside today?"

From location to decision

  1. 👤

    User

    Opens AirWise and types a city.

  2. 📍

    Select Location

    The Geocoding API turns the city name into coordinates. searchLocation()

  3. ☁️

    AQI API

    We ask the Air Quality API for that place. getAQIData()

  4. 📊

    Hourly AQI Data

    We get one AQI value for every hour of today. createHourlyChart()

  5. 🎨

    AQI Analysis

    Each value is matched to a category and color. getAQICategory()

  6. 🕒

    Best Time Calculation

    We slide a 3-hour window over the day and average it. findBestTime()

  7. 💚

    Health Recommendation

    Advice for groups and activities is chosen from the AQI. getRecommendation()

  8. ✅

    User Decision

    Go now, wait for the clean window, or stay in.

How the best time is calculated

  1. Take the 24 hourly AQI values for today.
  2. Look at every 3-hour window that starts now or later (for example 3 PM to 6 PM).
  3. Average the AQI inside each window.
  4. The window with the lowest average is the best time. The highest is the period to avoid.
  5. If even the best window averages above 100, we say no particularly clean period was found.

Chart library

None. The bar chart is built from plain HTML and CSS, so it is easy to explain.

Main functions in the code

  • searchLocation(city) finds the coordinates of a city.
  • getAQIData(place) downloads the air-quality data.
  • displayAQI() shows the big AQI card.
  • createHourlyChart() draws the hourly bar chart.
  • findBestTime() finds the cleanest and dirtiest 3-hour windows.
  • getRecommendation(aqi) returns the advice for an AQI value.
  • getAdvice(question) builds the AI Advisor answer.

About the data

Air-quality values come from the Open-Meteo Air Quality API, which serves model data from the Copernicus Atmosphere Monitoring Service (CAMS). It is a computer model of the atmosphere, not a reading from a sensor on your street, so it can differ from a local monitoring station. If the data cannot be loaded, AirWise shows an error instead of fake numbers.
